TrueFind iPhone（iOS）安裝與使用說明

免 Mac 電腦！直接從 Windows 電腦將 GitHub Actions 建置好的 TrueFind iOS 版安裝至實體 iPhone，並設定「背面輕點兩下」0 彈窗一鍵事實查核。

支援 iOS 16.0 以上 Windows + USB 傳輸線 免費 Apple ID 即可安裝 零網路權限・隱私優先

1 事前準備（Windows 電腦）

  1. 安裝 Apple 官方傳統版 iTunes 與 iCloud（Sideloadly 必要元件，請勿從 Microsoft Store 安裝）：
    • iTunes（Windows 64-bit 傳統安裝檔）：https://www.apple.com/itunes/download/win64
    • iCloud for Windows（傳統安裝檔，Sideloadly 官網亦提供連結）：https://sideloadly.io/
  2. 下載並安裝 Sideloadly（免費 iOS 側載簽章工具）：
    官網下載：https://sideloadly.io/
小提示：若希望每 7 天透過同一個 Wi-Fi 全自動背景續簽，也可以改用 AltStore；若希望初次安裝步驟最簡單，建議先用 Sideloadly。

2 下載最新版 iPhone .ipa 安裝檔

  1. 打開專案的 GitHub Actions 頁面：
    https://github.com/JUSTWT1999/TrueFind/actions
  2. 點進最新一筆綠色打勾的 TrueFind CI (Android & iOS) 建置紀錄。
  3. 滑到頁面最底部的 Artifacts 區塊，點擊下載 TrueFind-iOS-Unsigned-IPA。
  4. 將下載下來的 .zip 壓縮檔解壓縮，取出裡面的 TrueFind-iOS-unsigned.ipa。
注意：請務必先解壓取出 .ipa 檔案，不能把 .zip 直接拖進 Sideloadly。

3 用 Sideloadly 安裝到 iPhone

  1. 用 USB 傳輸線將 iPhone 連接到 Windows 電腦。若 iPhone 跳出「要信任這部電腦嗎？」，請點「信任」並輸入解鎖密碼。
  2. 打開電腦上的 Sideloadly：
    • iDevice：確認已偵測到你的 iPhone 型號。
    • IPA：將解壓後的 TrueFind-iOS-unsigned.ipa 拖曳到左側 IPA 圖示框。
    • Apple ID：輸入你的 Apple ID Email（若不想用主帳號，可另行免費申請備用 Apple ID）。
    • （選用）展開 Advanced Options 可勾選 Wi-Fi 自動續簽（Auto Refresh）。
  3. 點擊 Start，依提示輸入 Apple ID 密碼與 6 位數雙重驗證碼。
  4. 等待進度顯示 Done.，iPhone 桌面就會出現 TrueFind 圖示！

4 首次開啟前必做的 2 項 iPhone 系統設定

剛側載完成直接點開 App 會被 iOS 阻擋，請先完成以下兩步（只需做一次）：

  1. 信任開發者憑證：
    前往 iPhone 「設定 → 一般 → VPN 與裝置管理」 → 在「開發者 App」下方點選你的 Apple ID → 點 「信任」。
  2. 開啟開發者模式（iOS 16 以上必做）：
    前往 iPhone 「設定 → 隱私權與安全性」 → 滑到最下方點 「開發者模式」 → 開啟開關並依提示重新開機 → 重開後輸入密碼確認開啟。

5 設定「背面輕點兩下」0 彈窗一鍵截圖查核（約 30 秒）

「背面輕點（Back Tap）」是 iPhone 8 以上內建的官方手勢：看貼文時用食指在 iPhone 機背蘋果 Logo 附近輕輕敲兩下（叩、叩），系統會自動靜默截圖並瞬間彈出 TrueFind 查核面板。

步驟 A：建立 2 行 Apple 捷徑

  1. 打開 iPhone 內建的 「捷徑（Shortcuts）」App，點右上角 ＋。
  2. 依序加入下列兩個動作，並將捷徑命名為 「TrueFind 查核」 後點完成：
1. 📷 拍攝截圖
↓（系統會自動將螢幕截圖帶入下一步）
2. ✓ TrueFind：事實查核截圖

步驟 B：綁定手勢

  • 一般 iPhone（iPhone 8 以上）：前往 「設定 → 輔助使用 → 觸控 → 背面輕點 → 點兩下」 → 滑到最下方「捷徑」區選 「TrueFind 查核」。
  • iPhone 15 Pro / 16 以上：也可前往 「設定 → 動作按鈕 → 捷徑」 選擇 「TrueFind 查核」，按一下側邊實體按鈕即可查核。
首次執行提醒：第一次輕點背面兩下時，iOS 會跳一次確認「是否允許捷徑將截圖分享給 TrueFind？」→ 請點 「永遠允許」，之後即可享有完全 0 彈窗直達體驗！

6 其他兩種使用方式（系統分享＆長截圖自動拼接）

  • 系統分享延伸功能（Share Extension）：在 Threads / Facebook / Safari / 新聞頁點「分享 → TrueFind 查核」（Safari 可先拍「整頁截圖」直接分享）。在相簿一次勾選 2～5 張連續截圖分享給 TrueFind，會自動去除重疊處拼成 1 張長圖！
  • App 內免權限選圖拼接：打開 TrueFind 主頁點 「從相簿挑選 1～5 張截圖拼接查核（免相簿權限）」，同樣支援裁切與一鍵派發給 ChatGPT / Gemini。

7 常見問題（FAQ）

Q1：免費 Apple ID 側載 7 天到期怎麼辦？

TrueFind 本身沒有任何期限限制，7 天是 Apple 對免費個人側載憑證的系統規定。到期時只要用 Sideloadly 把同一個 .ipa 再覆蓋安裝一次（或開啟 Wi-Fi 自動續簽），原本設定的查核模板與捷徑都會完整保留。若未來以 Apple Developer 帳號（US$99／年）發佈至 TestFlight 為 90 天有效，正式上架 App Store 則為永久無期限。

Q2：安裝時出現 Maximum number of apps / App IDs 錯誤？

免費 Apple ID 在同一支 iPhone 最多同時側載 3 個 App，且 7 天上限 10 個 App ID。TrueFind 含「主 App ＋ Share Extension」共佔 2 個 App ID。若額度不足，可先移除其他側載 App，或在 Sideloadly 的 Advanced Options 勾選 Remove PlugIns（只裝主 App、僅佔 1 個 App ID，背面輕點與相簿選圖仍可正常使用）。

Q3：送到 Gemini 時只有照片進去、文字沒有自動填入？

這是 Gemini App 的接收行為限制。TrueFind 派發前已自動將最終查核指令複製到 iPhone 剪貼簿，進到 Gemini 後點輸入框選「貼上」即可送出。
